pyemread
========

pyemread is a Python package for reading experiments with multi-line passages.
It covers four steps: rendering passages as stimulus bitmaps with word-level
areas of interest; reading eye-movement recordings (EyeLink ASC files,
fixation tables from other software, Eye-Tracking-BIDS recordings or raw
samples); assigning fixations to text lines and words; and computing
word-level and sentence-level reading measures.
